# Icon credits

Logos belong to their owners and are used only to identify the link they open.

Logos added in v0.6.0 come from each site's own app icon or favicon, except
Project Gutenberg (Wikimedia Commons): canva, citation (ZoteroBib), cuny,
edgenuity, fafsa (Federal Student Aid), geogebra, gutenberg, libraryCatalog
(Follett Destiny), phet, photopea, regents (NYSED), scratch, sora, wayground,
writingLab (Purdue).

Links with no usable logo (apRegistration, boces, nysAid, programOfStudies,
university/SUNY) use [Material Symbols](https://github.com/google/material-design-icons)
(Rounded, filled, weight 700) by Google, Apache License 2.0, as 512×512 PNGs.
